# Red Dead Redemption 2 Takeover

**Quake** × Red Dead Redemption 2 · visual · idea by the team

Bring Red Dead Redemption 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped Red Dead Redemption 2 into Quake: masked outlaws, a bounty on my head, and Dead Eye slow-mo that tags and kills everyone.

## Install

Copy the mod folder next to Quake's id1 folder (LibreQuake works) and start Quake with the argument -game followed by the mod folder name. Load map lq_e0m1; press Q for Dead Eye once the bar is charged by kills.
